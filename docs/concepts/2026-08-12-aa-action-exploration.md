## 1. 탐색의 출발점

- 싱글플레이 3D PC 게임, 유료 AA급 품질을 지향한다.
- 실제 개발 착수는 약 2년 뒤를 상정한다. 아직 출시되지 않은 Unity 버전의 구체 API가 아니라 교체 가능한 기능 경계를 설계한다.
- 일반 구간에는 다수의 특징적인 잡몹과 트래시몹이 등장하고, 보스전은 소울라이크에 가까운 1대1 결투 감각을 지향한다.
- 로그라이크, 불렛 헤븐, 소울라이크를 표면적으로 합치는 대신 장르 사이의 긴장을 핵심 설계 문제로 다룬다.

## 2. 성능 테크 데모 가설

### 목표

- 목표 표시율: 144 fps 이상. 144 fps의 프레임 예산은 약 6.94 ms다.
- 스트레스 장면: 최대 500개체 스폰, 군중 이동, 전투 VFX, 조명 변화, APV 시나리오 전환.
- 평균 FPS가 아니라 프레임 시간 분포, 스폰 히치, GC 할당, CPU/GPU 병목과 장시간 안정성을 측정한다.
- 에디터가 아니라 실제 Windows 빌드와 고정된 해상도·목표 하드웨어에서 검증한다.

### 잠정 렌더링 구조

| 계층 | 잠정 선택 | 역할 |
| --- | --- | --- |
| 렌더 파이프라인 | URP Forward+ | PC용 다수 조명과 투명 효과를 포함한 기본 경로 |
| 대규모 시각 효과 | VFX Graph | 먼지, 불꽃, 충격파, 잔광, 환경 입자와 군중 효과 |
| 공간 간접광 | Adaptive Probe Volumes | 움직이는 개체에 픽셀 단위 베이크 간접광 제공 |
| 조명 상태 | APV Lighting Scenarios | Dormant/Awakened 등 서사적 조명 상태 전환 |
| 군중 애니메이션 | VAT + GPU 인스턴싱 | 잡몹과 원거리 군중의 대량 애니메이션·렌더링 |
| 군중 시뮬레이션 | 중앙 CrowdWorld, Jobs/Burst 가능 | 위치, 단순 AI, 전투 상태와 표시 계층 관리 |
| ECS | 보류/선택 백엔드 | CPU 시뮬레이션이 실제 병목일 때만 A/B 검증 |

### 중요한 경계

- ECS, VAT, GPU 인스턴싱은 대체재가 아니다. ECS는 게임 상태 계산, VAT는 애니메이션 변형, 인스턴싱은 반복 렌더 제출을 줄인다.
- VFX Graph는 게임 판정의 정본이 아니다. 명중, HP, 충돌과 적 상태를 CPU 쪽에서 확정한 뒤 위치·방향·강도만 전달한다.
- 500개의 VFX Graph 컴포넌트보다 효과 종류별 소수의 대형 그래프와 GPU 버퍼를 우선한다.
- Forward+는 무제한 그림자를 허용하는 면허가 아니다. 그림자 광원 수, 투명 오버드로, 후처리와 VFX를 별도 예산으로 관리한다.
- 미출시 Unity의 기능명에 결합하지 않고 CrowdSimulation, CrowdRenderer, CrowdAnimation, PerformanceHarness 경계를 유지한다.

## 3. 군중의 표현 계층

| 중요도 | 표현 | 게임적 권한 |
| --- | --- | --- |
| 핵심 적·보스 | 스켈레탈 애니메이션 | 정밀 피격, IK, 무기 소켓, 래그돌, 개별 연출 |
| 잡몹·트래시몹 | VAT + 인스턴싱 | 단순 충돌, 상태 기반 공격, 범위 판정, 부위 단순화 |
| 연출 군중 | VFX Graph·저LOD·임포스터 | 게임 규칙 없음 또는 매우 약한 대리 상태 |

VAT 잡몹은 배경 장식에 한정하지 않는다. 이동, 공격, 경직, 사망을 수행하되 팔다리 단위의 정밀 판정, 복잡한 Blend Tree, 즉석 래그돌과 개별 IK는 제한한다. 적의 게임 상태와 표현을 분리해 같은 EnemyId가 필요할 때 스켈레탈 캐릭터로 승격되고 안전한 상태에서 VAT로 강등될 수 있게 한다.

VAT 셰이더는 APV 수광, Lighting Scenario 블렌딩, Motion Vector/TAA 잔상을 별도로 검증한다. 인스턴스마다 월드 변환, 클립 ID, 재생 시간, 변형 ID, 피격 플래시, 사망 진행도와 LOD만 전달하는 구조를 가정한다.

## 4. 조명과 서사 표현

APV는 단순 최적화가 아니라 공간의 정서를 전달하는 기반이다. APV가 탑의 간접광과 방별 색을 깔고, Forward+의 제한된 직접광이 사건을 강조하며, VFX Graph가 불꽃·먼지·마력과 충격을 과장한다.

예시 Lighting Scenario:

- `Dormant`: 희미한 청색 간접광, 낮은 발광, 정적인 먼지.
- `Awakened`: 붉은 간접광, 활성화된 제단, 상승하는 재와 강화된 안개.

LightDirector는 APV 시나리오 블렌드, 핵심 직접광, VFX 파라미터, 후처리와 음악을 같은 사건 시간축에서 제어한다. 시나리오 조합 폭발을 피하기 위해 구역별 2개, 많아도 3개의 서사적 상태만 우선한다.

## 5. 전투 정체성: 조립하고 운용하는 액션

문제는 불렛 헤븐과 소울라이크의 간극이다. 자동 공격과 수치 성장을 강화하면 정밀 액션이 죽고, 조준·회피·패링을 강화하면 군중이 성가신 배경이 되기 쉽다.

잠정 해법은 다음 문장이다:

> 압박 속에서 전투 장치를 조립하고, 그 장치를 손으로 운용해 군중과 결투를 모두 돌파하는 액션 게임.

모듈 획득은 즉시 `+15%` 강화를 주는 선택지가 아니다. 플레이어는 본체, 급탄부, 발사부, 탄두/매질, 제어부를 연결해 새로운 작동 원리를 만든다. 강함은 선택 화면이 아니라 장전, 탄창 교체, 조준, 냉각, 탄종 전환, 부위 파괴와 같은 실제 운용 성공에서 나온다.

| 모듈 층 | 바꾸는 것 |
| --- | --- |
| 본체 | 기본 조작 리듬과 사용 가능한 연결부 |
| 급탄부 | 탄창 크기, 장전 방식, 지속 화력과 공백 |
| 발사부 | 단발, 점사, 충전, 관통과 반동 |
| 탄두/매질 | 파쇄, 분열, 표식, 흡수 등 적 대응 방식 |
| 제어부 | 안정성, 조준, 냉각, 과열과 위험 관리 |

군중전은 부품을 얻고 처리량과 공간 통제를 시험하는 구간이다. 보스전은 완성한 장치의 수치가 아니라 구조적 약점과 플레이어의 운용 숙련을 검사하는 1대1 결투다. 잡몹의 패턴은 보스 공격 문법을 미리 가르치고, 보스는 그것을 개인적인 의지와 정교한 타이밍으로 완성한다.

복잡한 조립은 안전지대나 짧은 정비 창에서 수행하고, 실시간 전투에서는 장전·탄종 전환·냉각·조준·부위 파괴를 수행하는 이중 구조를 우선 탐색한다.

## 6. 스킵에 견디는 내러티브

세계관은 설명보다 체험으로 전달한다. 내러티브는 세 층으로 나눈다.

| 층 | 전달 내용 | 방식 |
| --- | --- | --- |
| 필수 | 현재 위치, 목표, 사건의 결과 | 공간 변화, 적, 목표, 플레이 결과 |
| 선택 | 세계가 왜 이렇게 되었는가 | 유물, 기록, 우회 공간, 선택 대화 |
| 감정 | 플레이어가 무엇을 바꾸었는가 | 재방문, 인물·조명·음악·적 상태 변화 |

오프닝부터 Act 1의 브랜치는 거대한 플롯 나무보다 경로, 개입, 이해, 대가를 기록하는 합류형 구조를 우선한다. 모든 경로는 보스 게이트에 도달하지만, 플레이어가 본 것과 지불한 대가에 따라 보스의 의미와 이후 세계 상태가 달라진다.

다수전에서는 탑의 집단적 기능과 압력을 보여 주고, 보스는 그 시스템 속에서도 개별 의지를 가진 존재로 제시한다. 넓은 군중전 뒤에 적과 소리가 줄어드는 전실을 두고, 보스전에는 원칙적으로 추가 잡몹을 넣지 않아 1대1의 존중과 집중을 만든다.

## 7. 권장 프로토타입 순서

1. **성능 하네스**: 500 VAT 개체, URP Forward+, APV, VFX Graph, 조명 시나리오를 단계적으로 켜며 CPU/GPU 예산 측정.
2. **전투 샌드박스**: 주 무기 1개, 모듈 6~8개, 잡몹 3종, 부위 파괴 보스 1종.
3. **표현 검증**: VAT 승격/강등, APV 수광, TAA 모션 벡터, VFX 오버드로와 그림자 정책 검증.
4. **내러티브 슬라이스**: 짧은 오프닝, 첫 군중 돌파, 하나의 개입 브랜치, 정적 전실, 1대1 Act 1 보스.
