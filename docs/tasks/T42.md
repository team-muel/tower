# T42 — Interaction Runtime State Persistence

Carries T41 world interaction anchor state across renderer rebuilds without adding
new interaction rules.

## Scope

- Add a serializable Core snapshot shape for `AnchorRuntime`.
- Add a runtime store that captures per-anchor `state` and `usesRemaining`, then
  recreates guarded `AnchorRuntime` instances for matching `InteractableDef`s.
- Teach `InteractableRegistry` to export runtime snapshots.
- Wire `ForestFloorRenderer` so it captures all node registries before rebuild
  and restores matching anchor runtimes as the deterministic forest anchors are
  rebuilt.

## Non-scope

- No new reward effects.
- No new anchor kinds.
- No SaveGame JSON schema change yet. The snapshot DTO is shaped for that next
  step, but this task only persists within the live floor renderer lifecycle.
