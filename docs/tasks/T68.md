# T68 — command telemetry and live audit surface

**Branch** `task/T68-command-telemetry` · **PR title** `T68: measure package beta command loop`

## Purpose

Make package β's commander loop measurable while preserving its rules. The
owner needs to see whether a command was issued, replaced, consumed, expired,
or safely abandoned because the target became invalid.

## Implementation

- `CommandTelemetry` is Core-pure and owned by `RealtimeCommandBoard`.
- `AutonomousCombatDriver` records stale-order fallbacks; the board records
  stance inputs and precise-order lifecycle transitions.
- Generated encounters and the provisional run command panel expose the
  immutable telemetry snapshot.

## Verification gate

- EditMode covers the complete order lifecycle and stale-target fallback.
- Unity 6000.3.19f1 full EditMode and the generated-floor desktop flow remain
  the final gate when the editor is available.
