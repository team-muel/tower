## Contract (90 §3 완성 판정 원칙)

- `-qaAutoRun` (build-only QA seam) auto-plays the entire run through the
  REAL pipeline: it enters each scheduled encounter (detection, intro hold,
  combat, victory resolution are never bypassed) and advances floors after
  resolution. Defeat is not special-cased — the lifecycle's retreat path
  simply keeps being played.
- The desktop gate is: fresh run -> 7/8 events in floor order -> floor-ten
  boss -> conquest -> platinum grant -> save; relaunch -> the conquered run
  resumes from disk. Zero runtime exceptions throughout.
- Full EditMode regression and a clean Windows64 build remain merge
  conditions, as on every lane.
