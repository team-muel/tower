# T21 — 행동 순서 체인 Loadout (속도 튜닝 대체)

브랜치: `task/T21-order-chain` / PR 제목: `T21: action order chain loadout`
의존: T18~T20 (머지됨). 근거: 18 v2.6 정합 ③ — **숫자 속도 튜닝 폐기, 편성에서 행동 순서 체인에 로스터 배치**. (사용자 원문: "행동순위 우선 n체인에 각 로스터를 하나씩 넣는 느낌"; 확장 여지: 성향상 속도 고정이라 체인 지정 불가 인물 공존 가능 — 이번엔 필드 자리만.)

## 규칙 (v0)

1. **아군 순서 = 체인**: 편성 화면에서 파티(회귀자+동료 3)를 순서 슬롯 1~4에 배치. 라운드 내 아군의 상대 순서는 체인 그대로.
2. **적과의 병합**: 모든 유닛에 이니셔티브 값 부여 — 아군 = 체인 위치에서 파생(1번=100, 2번=90, 3번=80, 4번=70 — 상수 테이블, 하드코딩 스위치 금지), 적 = 기존 속도 스탯 그대로. 내림차순 병합 정렬(동률은 유닛 id — 기존 결정성 규칙 유지). → 빠른 적(속도>90)은 아군 1번보다 먼저 움직일 수 있음: **적 속도가 위협으로 읽히는 구조**.
3. `CharacterDef.speed`는 유지(적·성향 파생용), 아군 라운드 순서 계산에서만 체인이 우선. `chainLocked`(bool, 기본 false) 필드만 추가 — 성향 고정 인물 확장 자리(로직은 후속).
4. 체인은 원정 단위 저장(전진/후퇴 세이브에 포함).

## Loadout UI 변경

1. T14의 속도 ± 버튼 **제거**. 엔트리에 순서 뱃지(①②③④) 표시 + [▲][▼] 버튼으로 체인 재배치 (즉시 반영, QA press 등록 유니크 이름).
2. 헤더 힌트 갱신: "행동 순서를 정하고 출발 — 순서가 연계를 만든다".
3. 전투 이니셔티브 스트립(T17 HUD)이 체인 결과를 그대로 보여주는지 확인 (병합 정렬 반영).
