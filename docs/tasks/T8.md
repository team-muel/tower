# T8 — 원정 루프 + 전진/후퇴 세이브

브랜치: `task/T8-expedition-loop` / PR 제목: `T8: expedition loop + advance/retreat saves`
의존: T5·T6·T7 (모두 머지됨).

## 목표

수직 슬라이스의 매크로 루프: 편성 → 층 진행 → 전투 → 전진/후퇴 판정 → 세이브/롤백 → 숏컷. **규칙 로직은 Tower.Core 순수 C#** (테스트 대상), Unity 배선은 최소.

## v0 규칙 (11 Design Pillars §5 전진/후퇴 경제 — 이대로 구현)

- **원정 상태**: 현재 층계(v0: 층계 1개), 층 인덱스(1~N, v0 N=3), 파티(CharacterState들 + 사망 카운트), 후퇴 카운트, 숏컷 플래그.
- **전진** (층계 최상층 클리어): 사망 상태 동료를 로스터에서 **확정 제거** → 체크포인트 세이브 → 숏컷 획득.
- **후퇴** (파티 전멸 또는 자발적 후퇴): 직전 체크포인트 세이브로 **롤백**, 단 그 원정 중 사망했던 동료는 **사망 카운트 +1 얹고 생환**, 후퇴 카운트 +1.
- **3사 실종**: 사망 카운트 3 도달 동료는 롤백 시 생환하지 않고 **실종 마킹** (로스터에서 제외, 기록은 유지).
- **대회귀**: 후퇴 카운트 3 도달 → 층계 1·층 1로, 로스터 초기화(실종 기록은 유지), 후퇴 카운트 리셋. 숏컷 플래그는 **유지** (v0 결정 — 대회귀 시 유지물 목록은 후속 확정, PR 본문에 명시).
- **숏컷 v0**: 정복(전진 완료)한 층계는 재진입 시 정복 층 스킵 게이트.
- **세이브**: JSON 파일 (`%USERPROFILE%\AppData\LocalLow` 대신 v0는 `SavePath` 주입 가능하게 — 테스트에서 temp 경로 사용). 직렬화는 JsonUtility 또는 수동 — 결정 자유, PR에 명시.

## 산출물

1. `ExpeditionState` + `ExpeditionRules` (전진/후퇴/실종/대회귀 판정·적용, 순수 C#, Result 패턴).
2. `SaveGame` (직렬화 DTO) + `SaveRepository` (경로 주입, 저장/로드/롤백).
3. `ExpeditionRunner` (Tower.Combat/Gen 배선): FloorGenerator로 층 생성 → 조우 시 전투(TurnEngine+AiTurnDriver+AbilityResolver) → 층 클리어 판정 → 전진/후퇴 → 다음 층/롤백. **씬 파일 수정 금지** — 코드 부트스트랩(`ExpeditionDemoBootstrap`)으로.
4. EditMode 테스트 (핵심 게이트): 전진 시 사망자 확정 제거+세이브, 후퇴 시 롤백+카운트+1 생환, 3사=실종, 3후퇴=대회귀(로스터 초기화·숏컷 유지), 세이브 라운드트립(저장→로드 동일), 숏컷 스킵.
