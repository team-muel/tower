# T45 — ForestFloorRenderer prefab hooks (procgen path gets real assets)

**Branch** `task/T45-forest-prefab-hooks` · **PR title** `T45: forest floor prefab hooks`
**Assembly** `Tower.Floor` (+ pure helper, + tests in `Tower.Tests.EditMode`)

## Why

T44 landed 64 normalized wrapper prefabs and dressed the **hand-authored** build scene
(`Prototype.unity`). But `ForestFloorRenderer` — the thing that actually drives the
**procedural** 1층계(숲) from `FloorGraph` — still builds everything with
`GameObject.CreatePrimitive`. There is not a single serialized prefab field in the
project. So `_FloorPreview` (the procgen scene) still renders greybox capsules.

T45 closes that: the renderer instantiates prefabs when they are assigned, and falls
back to today's primitives when they are not.

## v0 rules (do NOT decide these yourself)

1. **Determinism is the contract.** Placement already comes from `ForestContentPlanner`
   / `NodeAnchorPlanner`, seeded by `_graph.Seed`. Prefab *selection* must be equally
   deterministic. **Never call `UnityEngine.Random`.** Use the existing
   `DeterministicRng` (`Assets/_Tower/Scripts/Floor/DeterministicRng.cs`) or an FNV-1a
   mix of `(seed, nodeId, propIndex)`.
2. **Selection logic must be pure and testable.** Put it in a `static` class with no
   `UnityEngine` object dependencies, e.g.
   `public static int PickIndex(int seed, int nodeId, int slot, int count)`.
   The MonoBehaviour calls it. This is convention #3 in `AGENTS.md`.
3. **Fallback, not replacement.** If a prefab array is null/empty, keep the current
   `CreatePrimitive` code path verbatim. All 525 existing EditMode tests must still pass
   with nothing assigned.
4. **Do not change the `AnchorMarker` contract.** The instantiated anchor root must still
   get `AnchorMarker` and `marker.Bind(nodeId, a.Def.Id, a.Kind, color)`.
   `WorldInteractionController` must not be touched — it resolves rules via
   `InteractableRegistry`, and that binding stays as-is.
5. **Do not edit scenes and do not open the Unity editor.** You work in a `git worktree`.
   Scene/inspector assignment is the orchestrator's job after merge. Do not create
   `.meta` files — the orchestrator generates them in the main tree.

## Deliverables

### 1. Serialized fields on `ForestFloorRenderer`

```csharp
[Header("Prefabs (optional - falls back to primitives when empty)")]
[SerializeField] private GameObject[] treePrefabs;
[SerializeField] private GameObject[] rockPrefabs;
[SerializeField] private GameObject[] bushPrefabs;      // may stay empty for now
[SerializeField] private AnchorPrefabEntry[] anchorPrefabs;  // kind -> prefab
[SerializeField] private GameObject exitMarkerPrefab;
[SerializeField] private GameObject bossMarkerPrefab;
[SerializeField] private GameObject eventMarkerPrefab;
[SerializeField] private GameObject playerPrefab;
```

`AnchorPrefabEntry` = `[Serializable] struct { public InteractableKind Kind; public GameObject Prefab; }`.
Resolve by `Kind`; missing kind → primitive fallback for that kind only.

### 2. Instantiate + fit + ground

The T44 wrapper prefabs have an **identity root** (scale 1, rotation 0) and a **foot
pivot** (world `bounds.min.y == 0` at scale 1). So:

```
go = Instantiate(prefab, parent);
go.transform.rotation = Quaternion.Euler(0, prop.YawDegrees, 0);
// measure the INSTANCE (never the prefab asset - see trap 2)
Bounds b = EncapsulateRenderers(go);
float s = b.size.y > 1e-4f ? prop.Height / b.size.y : 1f;
go.transform.localScale = Vector3.one * s;
// re-measure after scaling, then sit it on the ground
b = EncapsulateRenderers(go);
float gy = GroundY(nodeId, prop.Position.x, prop.Position.z);
go.transform.position += new Vector3(prop.Position.x - go.transform.position.x,
                                     gy - b.min.y,
                                     prop.Position.z - go.transform.position.z);
```

- Trees scale to `ForestProp.Height`, rocks to `ForestProp.Height`.
- Clamp scale to `[0.3, 2.5]` so a bad prefab cannot produce a 40 m tree.
- Prefab-instantiated props keep their own colliders; do **not** call `Paint()` on them
  (they carry authored shared materials — repainting would defeat T44).

## Traps (all cost us real time on 2026-07-09)

1. **Quaternius FBX roots carry `rotation (90,0,0)` and `scale 100`.** The T44 wrapper
   prefab absorbs that. If you instantiate the raw `.fbx` instead of the wrapper prefab
   under `Assets/_Tower/Prefabs/Art/`, and then set `transform.rotation`, **trees lie
   down**. Only ever instantiate the wrapper prefabs.
2. **`Renderer.bounds` on a prefab *asset* (not instantiated) is meaningless.** Measure
   the instance, and never reset its transform before measuring.
3. `useFileScale=false` makes `globalScale` multiply raw FBX units. Do not touch importers.
4. A non-kinematic `Rigidbody` on a ~1.9 m character tips over during play. Keep
   `isKinematic = true, useGravity = false`.
5. `git -C C:\Users\fancy\Tower ...` — never `cd` then `git`.
6. Commit with `-c commit.gpgsign=false`.
