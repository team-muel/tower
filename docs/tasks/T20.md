브랜치: `task/T20-analog-battlefield` / PR 제목: `T20: analog battlefield migration`
의존: T18·T19 (머지됨). 근거: 18 v2.6 정합 ④ — 격자 폐기 확정, 단 **거리·LoS는 인터페이스 추상화로 Core 순수성 유지**. 스파이크 참고만(코드 재사용 금지).

## 전략 (리스크 통제)

**추상화 → 아날로그 구현 → 플래그 전환.** 그리드 코드는 이번에 삭제하지 않는다 — `IBattlefield` 뒤로 양쪽을 넣고 아날로그를 기본값으로 켠다. 문제가 생기면 플래그 하나로 롤백 가능.

## 산출물

1. **`IBattlefield` (Tower.Core)**: 위치 타입 `BattlePos(float x, float y)`, `Distance(a,b)`(유클리드), `HasLineOfSight(a,b)`, `ClampMove(from, to, moveBudget)`, `IsOccupied/Occupant`, 유효 영역 판정. 구현 2종:
   - `GridBattlefieldAdapter`: 기존 GridMap 래핑 (셀 중심 좌표, 맨해튼→유클리드 근사 or 기존 규칙 보존 — 어댑터 안에서 처리).
   - `AnalogBattlefield`: 연속 좌표 사각 영역, 유클리드 거리, v0 장애물 없음(LoS 항상 true — 장애물·NavMesh는 후속 태스크로 명시), 유닛 반경 겹침 금지(간단 원형 충돌).
2. **거리 스케일**: 기존 정수 사거리·이동력을 아날로그 단위로 변환하는 상수(`1 grid unit = 1.0`) — 밸런스 수치 불변.
3. **엔진 통로 교체**: AbilityResolver(사거리·LoS), ActionScorer(이동 후보 = 이동 예산 반경 내 결정적 샘플링 — 시드 기반 각도/거리 격자 샘플 8~16점), AiTurnDriver, TurnEngine 이동 커맨드(목적지 BattlePos). 모두 IBattlefield만 보게.
4. **전장 생성**: FloorRoom의 GridMap은 유지(생성 데이터)하되 전투 진입 시 `AnalogBattlefield`로 변환(방 크기 → 영역, 유닛 초기 배치 좌표화).
5. **뷰**: UnitToken/GridView — 아날로그 모드에서 타일 하이라이트 대신 **이동 반경 링 + 목적지 마커**, 유닛은 연속 좌표 배치. 회귀자 수동 이동 = 반경 내 클릭.
6. **플래그**: `CombatSpaceMode { Grid, Analog }` — 기본 Analog, QA state에 노출.
7. **T9 시뮬**: IBattlefield 경유로 결정성 유지 (같은 시드=같은 결과 테스트 필수).
