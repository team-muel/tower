# T37 — Poly Haven URP Mask Maps

근거: vault `00 Current Status` 잔여 폴리시의 "아스팔트 mask map(러프니스)", `76 Floor Preview and Asset Sourcing Plan`, `docs/licenses.md`.

목표: 이미 커밋된 Poly Haven 아스팔트/자갈 PBR roughness/AO 맵을 URP Lit material이 소비할 수 있는 packed map으로 만든다. 새 게임 메커니즘이나 새 외부 자산을 만들지 않는다.

## v0 규칙

1. 대상은 현재 프리뷰에서 쓰는 `asphalt_01`, `gravel_floor_02` 두 개.
2. packed mask map 채널:
   - R: metallic, 현재 0.
   - G: ambient occlusion.
   - B: detail mask, 현재 1.
   - A: smoothness = `1 - roughness`.
3. 같은 mask map을 URP Lit의 `_MetallicGlossMap`과 `_OcclusionMap`에 연결한다.
4. 소스 rough/AO 파일은 원본 파일명과 ledger 출처를 유지한다.

## 산출물

1. `Tower.EditorTools.PolyHavenMaskMapBuilder`.
2. `asphalt_01_mask.png`, `gravel_floor_02_mask.png`와 `.meta`.
3. `M_Asphalt_PH`, `M_Dirt_PH` material 연결 갱신.
4. `docs/licenses.md` ledger 가공 노트 갱신.

## 완료 정의

- Unity batch `-executeMethod Tower.EditorTools.PolyHavenMaskMapBuilder.BuildAll` 성공.
- 두 mask map importer가 non-sRGB로 설정된다.
- material에 `_MetallicGlossMap`과 `_OcclusionMap`이 연결된다.
- Unity EditMode 전체 통과 또는 문서화된 사유로 생략하지 않는다.
