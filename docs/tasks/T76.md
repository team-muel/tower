# T76 — make transition phases observable

**Branch** `task/T76-qa-transition-phase` · **PR title** `T76: report run transitions in QA state`

T74 made retreat and conquest banners real input boundaries, but T71's QA
phase still reported `exploration` while the transition was visible. T76 makes
the existing phase field truthful without adding a new JSON key: the active
run transition reports `transition`, then returns to `exploration` or
`conquered` after expiry.

## Implementation

- `ForestFloorRenderer.QaPhase()` prioritizes the visible transition over the
  underlying run phase.
- EditMode captures the registered-state seam directly and verifies both sides
  of the unscaled banner lifetime.
