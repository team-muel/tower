# T74 — lock retreat transitions

**Branch** `task/T74-retreat-transition-lock` · **PR title** `T74: lock input during run transitions`

T66 added a visible retreat/conquest transition, but its overlay did not own
the corresponding input and QA timing gate. T74 makes the transition a real
run-state boundary: traversal, voluntary retreat, floor advance, and the
auto-run driver wait until the unscaled banner expires.

## Implementation

- `ForestFloorRenderer.IsTransitionBlocking` exposes the active transition
  without changing `RunLifecycle` authority.
- Fork entry, proximity traversal, voluntary retreat, and floor advance reject
  actions while a transition is visible.
- `QaAutoRunDriver` resets its settle timer during both encounter results and
  retreat/conquest transitions, preventing immediate re-entry behind the UI.
- EditMode covers traversal and floor-advance locking through the transition
  lifetime.
