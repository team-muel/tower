# T39 — Camera Occlusion Fade

근거: vault `00 Current Status` 잔여 렌더 정책 "가림 페이드 셰이더(DC-3)", `75 §6`, `76 Floor Preview and Asset Sourcing Plan`.

목표: 고정 아이소 카메라 정책은 유지하고, 카메라와 현재 follow target 사이에 끼는 런타임 Renderer만 일시적으로 투명 처리한다. 새 전투 기능을 만들지 않는다.

## 산출물

1. `CameraOcclusionFadeController`
   - camera→target sphere cast로 occluder Renderer 탐지.
   - target 자신은 제외.
   - occluder는 투명 material clone으로 교체하고, 경로에서 벗어나면 원래 material로 복원.
2. `OcclusionFadeMaterial`
   - URP Lit/Standard material alpha와 transparent render state를 설정.
3. `FixedIsoFollowCameraRig` 연결
   - camera 생성 시 controller를 보장.
   - focus target 변경 시 occlusion target 갱신.
4. EditMode 테스트
   - transparent material state와 alpha 적용 확인.
   - blocking renderer fade/restore 경로 확인.

## 완료 정의

- Unity EditMode 전체 통과.
- `FixedIsoFollowCameraRig`가 focus target 기반 가림 페이드 컨트롤러를 소유한다.
- 원본 material을 직접 훼손하지 않고 clone/restore한다.
