## v0 규칙 결정 (이대로 구현 — 변경 시 PR 본문에 근거)

- **부여(Apply)**: 대상에게 마크 적용 (MarkDef 지속턴, 스택 규칙은 MarkDef 따름) + 기본 위력 데미지(0 가능).
- **소모(Consume)**: 대상이 해당 마크 보유 시 마크 제거 + 기본 위력 × 소모 보너스 배율(v0: 1.5x, 상수로 두되 데이터 이동 가능하게) 데미지. 마크 없으면 기본 위력만 (실패 아님).
- **증폭(Amplify)**: 이번 턴/다음 아군 행동에 배율 버프 (v0: 대상 아군에게 1턴 지속 "증폭" 상태 — 그 유닛의 다음 능력 위력 × amplifyMultiplier).
- 데미지 v0: `max(1, 위력 + 공격 - 방어)` (모든 배율 적용 후 반올림).
- 사거리: GridDistance 맨해튼. LoS v0: 차단 셀이 직선 경로(브레젠험)에 있으면 불가. 대상 유형(적/아군/셀) 검증.
- 모든 실패는 Result 패턴 (사거리 밖, 잘못된 대상, 죽은 대상 등).
