의존: T2 (머지됨). T3/T4와 병렬 — **그쪽 타입(TurnEngine 등)에 의존하지 말 것.** Tower.Gen에 구현 (Core의 GridMap/GridPos는 사용 가능).

## 목표

시드 결정적 층 생성기. 씬·MonoBehaviour 금지 — 순수 데이터 생성 (시각화는 후속).

## v0 규칙 결정

- 층(Floor) = 방 그래프: **방 3~5개**, 선형 경로 + 최대 1 분기. 마지막 방 = 출구(층계 내 다음 층으로).
- 방 = 직사각 그리드 (8×8 ~ 14×14), 문 연결 (edge에 문 좌표).
- 조우 배치 문법: 방 크기·깊이(입구로부터 거리)에 따라 적 수 결정 — `enemyCount = clamp(1 + depth + sizeBonus, 1, 5)` v0. 입구 방은 조우 없음. 보스층 플래그가 있으면 마지막 방 = 보스 조우 1.
- 같은 시드 + 같은 파라미터 = 완전 동일 출력 (System.Random(seed), 순회 순서 고정).

## 산출물

1. `FloorGenerator.Generate(FloorGenParams params)` → `FloorLayout` (방 목록: GridMap + 문 + 조우 스펙(적 수·종류 슬롯), 그래프 에지, 입구/출구/보스 플래그).
2. `FloorGenParams`: seed, roomCountRange, bossFloor 여부 등.
3. EditMode 테스트: 시드 결정성(같은 시드 2회 = 동일 직렬화 결과), 방 수 범위, 그래프 연결성(모든 방 도달 가능), 입구 방 무조우, 보스층 규칙.
