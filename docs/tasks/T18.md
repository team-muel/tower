## 규칙 (v2.6 확정)

1. `AbilityDef.cooldownRounds` (int, 0=쿨타임 없음). 데이터 필드 — 기존 슬라이스 에셋 몇 개에 1~2 값 부여.
2. `CharacterState`에 유닛별 능력 쿨타임 추적 (`RemainingCooldown(abilityId)`), 라운드 경계에서 1 감소. **순수 C#, Result 패턴 유지, UnityEngine 참조 금지.**
3. **PendingAbility**: 유닛 턴 시작 시, 장착 슬롯(1~4) 중 쿨타임이 아닌 능력에서 **시드 결정적 무작위**로 1개를 예비 상태로 픽. 전부 쿨타임이면 "기본 행동"(무태그 능력이 있으면 그것, 없으면 스킵) 폴백.
4. `TurnEngine.SetPendingAbility(unitId, abilityId)` — 회귀자 개입(불릿타임 Direct Select의 엔진측 계약): 쿨타임 아닌 장착 능력으로만 교체 가능(Result 실패 사유 명시).
5. 능력 사용 성공 시 해당 능력에 cooldownRounds 기록.
6. **성향 스코어러(T5)는 유지**: 이동·타겟팅은 기존 ActionScorer가 결정하되, 사용 능력은 PendingAbility로 고정된 것을 사용하도록 AiTurnDriver 조정. 연계 인지(소모 우선 등)는 **타겟 선택**에 계속 작동.
7. AutoBattleSimulator(T9)가 새 규칙으로도 결정적으로 동작해야 함 (시드 → 동일 결과).
