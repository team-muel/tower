## 목표

속도 기반 개별 이니셔티브 턴 엔진. **Tower.Core의 순수 C#** — MonoBehaviour·씬 금지. 연출(프레젠테이션)은 엔진 밖 계약으로 분리.

## v0 규칙 결정 (이대로 구현 — 변경 시 PR 본문에 근거)

- 이니셔티브: 라운드 시작 시 생존 유닛을 **속도 내림차순** 정렬 (동속은 유닛 id 사전순 — 결정적). 속도 변화는 **다음 라운드부터** 반영.
- 턴 구조: 라운드 → 유닛 턴 순회. 유닛 턴 = 이동(이동력 4) + 액션 1 (v0 고정).
- 사망 유닛은 큐에서 즉시 제외. 전투 종료 판정: 한쪽 전멸.
- **연출 타임박스**: 엔진은 연출을 기다리지 않는다 — `IActionPresenter` 인터페이스(행동 이벤트 수신, 완료 콜백)로 분리하고, 즉시완료(NullPresenter) 구현 포함. 5초 상한 강제는 프레젠터 계약 문서화 + 테스트용 타임아웃 헬퍼로.

1. `TurnEngine` (라운드/턴 상태기계, 이니셔티브 큐), `CombatantRef`(T1 CharacterState 연결), `IActionPresenter` + `NullPresenter`.
