# T40 — 1층계(숲) 절차생성: 공간 레이아웃 + 걸어다닐 렌더 + 가시 갈림길 순회 + Ascend (v0)

## 설계 근거 (요지)
- **공간 모델(정본)**: 서울=캠프(탑 밖). 탑 진입 → **1층계 = 숲 바이옴(탑 내부 코어 공간)**. 숲 = 인게임 절차생성 대상. DE 마르티네즈 = 스타일 참조 전용.
- **골격은 이미 있음**: `FloorGenerator.Generate` → `FloorGraph`(노드 3~5 + 스텝마다 route 2갈래 = **DD2 갈림길**, 둘 다 다음 노드로 = "안전/위험 두 길, 같은 방으로"). 결정적. 손대지 말 것.
- **갈림길 = 월드에 보이는 디에게틱 선택**(SoD식 웨이포인트 메뉴 아님): 노드 출구에서 **두 갈래가 눈에 보이고 걸어가서 선택**. 숲 형태 = 갈라지는 두 오솔길(+RouteType 힌트). (Hades 문/DE 포탈/DD2 길의 숲판.)
- **수직 체감 = Ascend 의식**(39 Shape of Dreams 참조): 출구 노드 도달 → 파티가 **물리적으로 상승하는 전환 연출**로 2층계로. 수직 지오메트리 재설계 불필요.
- **전투 필드 = 길쭉**(상하 또는 좌우로 elongation), **중간중간 손제작 이벤트 필드**(v0=플래그+플레이스홀더).

## 산출물

### T40a — Core (`Tower.Gen`, 순수·테스트) [Codex 발주]
`FloorLayout` (또는 `FloorSpatialLayout`): `FloorGraph` → **결정적 공간 레이아웃**.
- 노드별 월드 위치 + **길쭉한 필드 치수**(elongation 파라미터: 예 축 방향 1.0, 교차축 0.5~0.6).
- 스텝마다 **2 route(fork)의 좌/우 trail 경로점**(노드 i 출구 → 좌 trail(route A) / 우 trail(route B) → 노드 i+1 입구). RouteType를 trail에 부착.
- Core 순수(UnityEngine **무참조**). 결정성(seed 동일 → 동일 레이아웃).
- **EditMode 테스트**: 결정성, 노드 수/위치, 스텝당 fork=2, trail이 i→i+1 연결, elongation 반영.

### T40b — Render/Traversal (`Tower.UI` 등) [Claude 서브에이전트 co-dev]
`ForestFloorRenderer` MonoBehaviour: `FloorGraph` + `FloorLayout` + `BiomeTheme.Forest` 소비.
- 노드 = **걸어다닐 숲 세그먼트**: `HeightFieldFactory.ForNode` 지형 위에 **결정적 나무/공터/오솔길/바위**(seed·nodeId 파생), 길쭉한 필드. MeshCollider로 지면추적 지원.
- **가시 갈림길**: 노드 출구에 좌/우 두 trail을 **눈에 보이는 걸어갈 오솔길**로 렌더 + RouteType 색/표식 힌트(Safe/Combat/Hazard/Special). (보상 프리뷰는 후속.)
- **순회**: 플레이어가 trail로 진입하면 다음 노드로 이동, `FloorExploration.MarkVisited/MarkScouted`.
- **이벤트 노드**: 손제작 이벤트 자리 = 플래그 표식(플레이스홀더 큐브/사인). v0는 표식만.
- **Ascend**: 출구 노드 도달 → 파티/카메라 상승 전환 연출(placeholder도 가능; ascendHeight/duration/ease 파라미터).

## v0 규칙 (작업자가 바꾸지 말 것)
- 결정적(seed). 전투/조우 = **빈 껍데기**(노드에 표식만, 실제 전투 T-후속).
- 이벤트 필드 = 플래그 + 플레이스홀더(손제작 실템플릿은 후속).
- Core에 UnityEngine 참조 금지. 렌더는 UI/씬 계층.
- 기존 `FloorGenerator`/`FloorGraph`/`RouteType` 계약 변경 금지(소비만).
- 미결(색 힌트 구체·Ascend 연출 디테일)은 v0로 단순 구현 + PR 본문에 근거 명시.
