# T33 — Fixed Iso Follow Camera

근거: vault `75 §6 DC-3`, `00 Current Status` 잔여 폴리시.

목표: T19의 전투 `OrbitCameraRig`를 폐기하고, 확정된 카메라 정책인 **고정 아이소 각도 + 대상 팔로우 + 줌, 회전 없음**으로 바꾼다. 새 전투 기능을 만들지 않는다.

## v0 규칙

1. 회전 입력 금지.
   - Q/E yaw step 제거.
   - 우클릭 드래그 yaw/pitch orbit 제거.
   - devcam도 pitch/distance/FOV 튜닝만 유지하고 yaw 조작은 만들지 않는다.
2. 팔로우 유지.
   - 탐험/전투 모두 대상 팔로우 구조는 유지.
   - 전투에서는 현재 턴 유닛, 없으면 회귀자 fallback.
3. 줌 유지.
   - 스크롤 zoom과 devcam distance 조정은 유지.
4. presentation offset 유지.
   - T22 카메라 shake는 계속 동작해야 한다.
5. 기존 `IsoCameraRig`와 충돌 금지.
   - 캠프/탐험 기존 iso rig를 망가뜨리지 않는다.
   - Expedition 전투 카메라만 새 fixed rig로 교체한다.

## 산출물

1. 새 전투 카메라 rig 또는 기존 orbit rig의 명확한 대체.
   - 권장: `FixedIsoFollowCameraRig` 신규 타입.
   - `OrbitCameraRig` 이름을 계속 쓰는 것은 설계와 어휘가 충돌하므로 피한다.
2. 순수 수학 테스트 갱신.
   - yaw normalize/step 테스트는 제거 또는 legacy로 격리.
   - fixed yaw/pitch offset, pitch/distance clamp, distance 보존 테스트.
3. 호출부 교체.
   - `PlayableExpeditionController`
   - `CombatJuicePresenter`
   - `CameraTuningModeController`
4. docs/task와 주석 갱신.

## 완료 정의

- EditMode 전체 통과.
- repo에 `OrbitCameraRig` 런타임 참조가 남지 않는다. 단, 삭제된 파일명이나 문서 과거 기록은 제외.
- 전투 카메라가 회전 입력을 읽지 않는다.
- 카메라 shake/presentation offset 테스트 또는 호출 경로가 유지된다.
