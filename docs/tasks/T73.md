# T73 — readable status-only combat abilities

**Branch** `task/T73-status-ability-feedback` · **PR title** `T73: show status-only combat feedback`

T70 made damage readable, but a successful zero-damage status action could
still look like nothing happened. T73 carries the existing
`OnAbilityResolved` observer callback into the presentation queue and shows a
small world-space result for Amplify and other zero-power status abilities.

## Implementation

- `CombatPresentationEventBuffer` now preserves successful ability-resolution
  events separately from positive damage events.
- `CombatFeedbackPresenter` shows `AMPLIFY` or `MARK` on the resolved target,
  with a heal-colored Amplify profile and a short target pulse. Damage actions
  keep their existing number-only presentation, avoiding duplicate popups.
- The Core observer and simulation remain authoritative; the queue is drained
  after each generated-floor simulation step and uses only local unscaled
  presentation time.
- EditMode covers Amplify feel resolution, ability event ordering, and observer
  forwarding.
