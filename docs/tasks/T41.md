# T41 — M4 World Interaction Wiring

Wires the T29 interaction Core (InteractableDef/Registry/Resolver — complete, tested,
previously unconnected to the world) into the generated forest floor.

## What landed
- `NodeAnchorPlanner` (Tower.Floor, pure/deterministic, mirrors `ForestContentPlanner`):
  maps a node's role → interaction anchor kinds and places them in the tree-free
  clearing. Entrance=Inspect, Camp=Shrine+Grave(after-death), Boss=Chest, Exit=Resource,
  Normal=seeded {Chest/Resource/Trap}. Positions clamped inside the field.
- `NodeAnchorPlan` / `PlacedAnchor`: immutable plan (Core `InteractableDef` + world XZ).
- `AnchorMarker` (MonoBehaviour): world identity (nodeId, anchorId, kind) + state reflection.
- `WorldInteractionController` (MonoBehaviour): thin glue — nearest eligible anchor in the
  current node, resolves via the node `InteractableRegistry` + `InteractionContext`, walk-up
  + key (E) to use. No rules in the controller (all in tested Core). AX2-safe (no button menu/grid).
- `ForestFloorRenderer`: per node builds the anchor plan, binds a per-node registry,
  instantiates kind-tinted placeholder primitives, and auto-attaches the controller.
