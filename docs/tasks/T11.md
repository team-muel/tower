## 설계 근거 (자체 포함)

- 캠프 = 이동 거점: 전투 없는 방. v0 효과 = 파티 HP 30% 회복 + 대화 이벤트 훅(자리표시자 인터페이스만). 캠프도 전진/후퇴 세이브에 포함되는 상태.
- 층계 바이옴 (캐논): 1층계=숲, 2=사막, 3=유령저택, 4=수정광산/소금사막. 시각 테마 = 조명·색·안개 파라미터 (그레이박스 위에 조명으로 분위기 — 에셋 0원 전략).

## 산출물 (Tower.Gen + Tower.Core, 순수 C# 위주)

1. `RoomKind` enum (Normal/Entrance/Exit/Boss/**Camp**) — FloorRoom에 통합 (기존 bool 플래그와 호환 유지 또는 마이그레이션, 기존 테스트 깨지지 않게).
2. 생성 규칙: `FloorGenParams.IncludeCamp=true`면 출구 직전 방 1개가 캠프로 지정 (조우 없음). 시드 결정성 유지.
3. `CampRules` (Tower.Core): 캠프 입장 시 파티 HP 30% 회복(반올림, 최대치 초과 금지), 사망자에겐 효과 없음. `ICampEventHook` 인터페이스 (대화 시스템 자리표시자 — 구현은 후속).
4. `BiomeTheme` 데이터: id(Forest/Desert/GhostManor/CrystalMine), ambient color, fog color/density, directional light color/intensity, tile tint 2색. `FloorGenParams`에 biomeId → `FloorLayout`에 전달. **적용(렌더링)은 범위 밖** — 데이터와 전달 경로만.
5. EditMode 테스트: 캠프 삽입 규칙(위치·무조우·시드 결정성 유지), 회복 규칙(경계: 만피, 사망자), 바이옴 전달.
