## 공통 UX 규칙 (이 태스크부터 게이트)

1. 가능한 모든 행동은 화면 안에 보인다 (넘치면 스크롤).
2. 비활성 버튼엔 사유 표시. 로딩 중엔 로딩 표시.
3. 미구현 기획 요소는 숨기지 않고 회색+"(준비 중)" 자리 표시.
4. 화면 진입 3초 안에 "여긴 어디, 뭘 하는 곳"이 읽힌다.

## 산출물 (Loadout 씬)

1. **스크롤 리스트**: 파티 4인 전원 (uGUI ScrollRect). 엔트리 = 이름 / HP / 속도 + [-][+] 버튼(기존 AdjustSpeed 재사용) / 능력 슬롯.
2. **능력 슬롯 표기 강화**: 능력명 + 태그 뱃지(부여/소모/증폭 — 색 텍스트 뱃지: 부여=청, 소모=적, 증폭=금) + 마우스오버 툴팁(위력, 사거리, 태그 설명 1줄). AbilityDef 데이터에서 읽기 — 하드코딩 금지.
3. **하단 고정 바**: [뒤로] [원정 출발] — 스크롤과 무관하게 항상 표시.
4. **상단 안내 갱신**: "회귀자 + 동료 3 — 고정 파티 (영입은 준비 중)" + 속도 튜닝 힌트.
5. **출발 로딩 상태**: 출발 클릭 → 버튼 비활성 + "탑을 오르는 중..." 표시 후 씬 전환.
6. QA 등록 유지: 스크롤 안 엔트리 버튼들도 QaRuntime 등록 (이름 유니크 규칙 유지).
