## Owner priorities (2026-07-14)

Terrain generation and map structure for the first stair-step outrank art
procurement; the only enemy that must read properly right now is the pillbug
(공벌레). Party traversal follows [[89 Party Traversal Vision v2]].

## Contract

- **Per-floor deterministic terrain (`FloorSeeds`)**: every floor of the
  stair-step derives its own terrain seed and travel-length stretch
  ([0.85, 1.15]) from the authored base seed. Ten floors stop being clones of
  one map while staying fully reproducible. The floor-advance path also stops
  reusing a stale stub layout (latent T58 bug: `_layout` was created once and
  never rebuilt); injected layout sources are still respected.
- **89 movement contract (`BreadcrumbTrail`)**: the leader's trajectory is
  recorded as a distance-based breadcrumb stream (rule 1); slots consume the
  same stream at per-slot distance delays (rule 2) with small alternating
  path-normal offsets, not a world-offset formation (rule 3); samples clamp to
  the recorded tail so followers can never overtake the leader (rule 5).
  Follow values are provisional world-unit scalings of the animatic's
  1.05-per-slot delays. The fixed formation offset survives only as the
  spawn-moment fallback and the combat handoff is unchanged.
- **Pillbug embodiment (`PillbugBodyBuilder`)**: segmented procedural body
  (abdomen, four arched shell plates, head with antennae, six stub legs) built
  from primitives with a single root collider — zero asset procurement. All
  four authored `EnemyCombatProfile` assets opt in via the new
  `bodyStyle: Pillbug` field (default `Primitive` keeps legacy bodies).
  The existing windup->commit telegraph (`PillbugBrain`) is untouched and now
  reads against a body with visible facing.
