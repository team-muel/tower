# T43 — Interaction SaveGame JSON Integration

Stores T42 interaction runtime snapshots in the existing checkpoint save JSON
without adding interaction effects or new gameplay rules.

## Scope

- Add `SaveGame.anchorStates` as a serializable array of `AnchorRuntimeSnapshot`.
- Extend `ExpeditionSaveMapper.ToSave` with an optional snapshot input.
- Add `ExpeditionSaveMapper.ToInteractionStore` to restore a save file's anchor
  snapshots into an `InteractionRuntimeStore`.
- Keep existing call sites unchanged: saves with no interaction state still emit
  and load an empty anchor-state array.

## Non-scope

- No new anchor kinds.
- No reward-table effects.
- No decision about whether advance, retreat, or great regression clears world
  anchors. That rule belongs to a later expedition/world integration task.
