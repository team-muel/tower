브랜치: `task/T15-camp-hub` / PR 제목: `T15: camp hub scene v0`
의존: T13·T14 (머지됨). 배경: 시작 시퀀스 재설계 — Boot 다음은 구성 화면이 아니라 **장소** (Hades 2의 Hub_Main→Hub_PreRun 구조 참조, vault 32).

## 흐름 변경 (이 태스크의 본체)

```
Boot [New Expedition/Continue] → Camp 씬(신규) → 출발 게이트 상호작용 → Loadout(기존 씬 재사용) → Expedition
```
- Boot의 두 버튼 모두 Camp로 이동 (Continue는 세이브 로드 후 Camp).
- Loadout 씬의 [뒤로]는 Camp로.

## Camp 씬 v0 산출물

1. **공간**: 그레이박스 캠프 (평면 + 프리미티브 소품 몇 개: 모닥불(포인트라이트), 텐트 큐브 2, 출발 게이트 아치). 코드 생성(씬 파일 최소).
2. **회귀자 조작 (DE식 이동 둘 다)**: WASD/방향키 직접 이동 + **마우스 우클릭 지점 이동**(클릭 지점으로 걸어감, 도착 시 정지). 캡슐 프리미티브 + 간단 이동속도. 새 Input System 사용 (프로젝트는 Both 모드).
3. **카메라**: 기존 IsoCameraRig 재사용 — 회귀자 추적(v0: pitch 52, 기본 14m, 감쇠 0.12s), 스크롤 줌 상시. -devcam 튜닝 모드 호환 유지.
4. **상호작용 존 시스템 (데이터 주도, Hades 존 참조)**: `CampZoneDef`(id, 위치·반경, 라벨) — 진입 시 화면 하단에 "[E] <라벨>" 프롬프트, E(또는 좌클릭)로 발동. v0 존 2개:
   - **출발 게이트**: 발동 → Loadout 씬 로드.
   - **모닥불**: 발동 → 자리표시 텍스트("동료들이 모닥불 곁에 있다. (대화는 준비 중)" — UX 규칙 3: 회색 준비 중 표기).
5. **층계 톤 연동 준비만**: 캠프 조명 파라미터(ambient/광원 색)를 T11 BiomeTheme에서 읽을 수 있는 훅 (v0는 1층계 고정값).
6. **UX 게이트 (21 §0)**: 진입 3초 규칙 — 상단에 "캠프 — 1층계 앞" 라벨. 이동법 힌트 1줄(첫 진입 시). QA 등록: 존 발동을 press로 노출(`press Depart Gate` 등), state에 씬·회귀자 위치 포함.
