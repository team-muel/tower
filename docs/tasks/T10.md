# T10 — 플레이어블 빌드 (씬 배선 + 메뉴 + Windows standalone)

브랜치: `task/T10-playable-build` / PR 제목: `T10: playable build`
의존: T0~T9 전부 머지됨. **이 태스크의 산출물은 코드가 아니라 "더블클릭으로 실행되는 게임"이다.**

## 목표

Unity를 모르는 사용자가 에디터 없이 게임 루프를 플레이할 수 있게 한다: Boot(메인 메뉴) → Loadout(편성) → Expedition(원정: 절차 층 + 그리드 전투 + 전진/후퇴) → 결과 → 메뉴. 그리고 **Windows 64bit standalone 빌드**를 뽑는다.

## 산출물

1. **Boot 씬**: 타이틀("Tower (가제)"), 버튼 3개 — 새 원정 / 이어하기(세이브 있으면 활성) / 종료. uGUI, 프리미티브 스타일이면 충분.
2. **Loadout 씬**: 기존 T6 편성 요소 활용 — 파티(회귀자+동료 3) 표시, 능력 슬롯 확인, 속도 조정 UI(있는 것 활용, 없으면 간단 +/-), "원정 출발" 버튼.
3. **Expedition 씬**: ExpeditionRunner 기반 — 절차 층 시각화(T2 GridView), 방 이동, 조우 시 전투(T3~T6 풀스택: AI 동료 + 회귀자 조작 + 오더 HUD), 층 클리어 → 다음 층, 최종 층 클리어 = 전진(세이브 + 결과 화면) / 전멸 = 후퇴(롤백 안내 화면) → Boot 복귀. 3후퇴 대회귀도 안내 화면.
4. **씬 파일 실제 배선** (이번엔 씬 수정이 태스크의 본체) + Build Settings에 3씬 등록.
5. **빌드 스크립트**: `Assets/_Tower/Scripts/Editor/BuildRunner.cs` — `-executeMethod`로 Windows64 빌드 → `C:\Users\fancy\Tower\Builds\Tower\Tower.exe` (Builds/는 gitignore에 이미 포함 확인, 없으면 추가).
6. 실행 확인: 배치모드 빌드 성공 + exe 파일 존재 확인. EditMode 테스트 전체(105+) 통과 유지.
