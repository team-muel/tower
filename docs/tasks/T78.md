# T78 — 모바일 Work 착수·정합 프로토콜

## 배경

휴대폰 Work와 Notion에서 나온 소유자 입력이 로컬 vault에 즉시 반영되지 않았다는 이유만으로 “비정본”으로 강등됐다. 동시에 GitHub `main`의 `AGENTS.md`는 로컬 Tower vault의 2026-07-13 실시간 전투 정정을 반영하지 않고 “3D 그리드 턴제”를 고정 요약으로 유지하고 있다.

## 목표

- Notion Tower를 모바일 인입·작업 제어면으로 정의한다.
- 단일 `Canonical` 판단 대신 출처 권한·설계 성숙도·동기화·구현의 네 축을 사용한다.
- 로컬 vault가 없는 모바일 세션도 안전한 문서·브리프·격리 스파이크와 Draft PR을 착수할 수 있게 한다.
- `AGENTS.md`를 오래된 설계 요약이 아니라 최신 상태로 안내하는 작업 계약으로 교정한다.

## 범위

- `docs/process/mobile-work-protocol.md` 신규 작성
- `AGENTS.md`의 설계 조회·모바일 착수 규칙 교정
- Notion `Creations / Tower` 부모 페이지와 모바일 프로토콜 페이지 연결
- 로컬 Tower vault에 동일 프로토콜과 상태 정정 기록

## 비범위

- Tower 게임 코드·Unity 에셋 변경
- T77 AA 액션 방향을 현행 Tower 피벗 또는 별도 신작으로 확정
