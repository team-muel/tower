# T70 — package β combat feedback bridge

**Branch** `task/T70-combat-feedback` · **PR title** `T70: wire combat hit feedback`

T67–T69 made the package-β loop commandable. T70 makes a successful ability
readable in the generated-floor fight: Core observer callbacks are forwarded to
a presentation-only queue, which drives world-space damage numbers and a short
target pulse. `AbilityFeelResolver` now affects popup style, lifetime/rise, and
pulse strength in the live runtime.

The bridge keeps the simulation authoritative and deterministic. It does not
write `Time.timeScale`, change combat state, or add a package; local unscaled
animation handles the provisional presentation. The existing `AbilityFeelDef`
data remains the art/tuning seam.
