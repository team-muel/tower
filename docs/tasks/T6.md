브랜치: `task/T6-player-turn-ui` / PR 제목: `T6: player turn UI + orders`
의존: T4 (머지됨). T5와 병렬 가능 — **T5 타입(ActionScorer 등)에 의존하지 말 것.** 오더는 "다음 자기 턴에 강제 행동 지시"를 남기는 데이터로 구현 (T5가 나중에 소비).

## 목표

회귀자(유일한 수동 유닛)의 턴 조작 UI + 오더 시스템 데이터 계층. Tower.UI + Tower.Combat.

## v0 규칙 결정

- 회귀자 턴 UI: 이동 가능 셀 하이라이트(T2 TileHighlighter 활용) → 클릭 이동, 능력 버튼 바(할당 슬롯 능력) → 대상 선택(유효 대상 하이라이트) → 실행. 스킵 버튼.
- **오더 v0 1종 "집중(Focus)"**: 대상 적 1 지정 → 모든 동료에게 1턴짜리 오버라이드 태그 부여 (`FocusOrder(targetId, expiresRound)`). 소비는 T5의 AI가 하도록 **순수 데이터(OrderBoard)로만 구현** — AI 배선은 T5/후속에서.
- 오더 자원: 전투당 2회 (13 §6 미결의 v0 — 하드코딩 말고 상수 클래스).
- UI는 uGUI (프리미티브 버튼·텍스트, 스타일링 불요). IActionPresenter 구현 1개(로그 프레젠터 또는 간단 트윈 — 5초 상한 준수, 스킵 가능).
