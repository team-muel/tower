# T69 — player ability input in package β

**Branch** `task/T69-player-ability-input` · **PR title** `T69: wire player ability orders`

The package-β command loop now reaches the player as well as companions. During
the existing Left Shift bullet-time command window, Z/X/C/V select the first
four player loadout slots and submit a one-shot precise order. The host keeps
target selection deterministic and intentionally small for this lane:

- enemy abilities target the nearest living enemy;
- cell abilities target that enemy's occupied cell;
- ally abilities target the player.

The player remains externally positioned and can move into range; a stale,
out-of-range, or otherwise invalid order follows the existing Core fallback and
telemetry path. No new recharge, counter, or timing rule was introduced.
