# T58 — Run lifecycle

**Branch** `task/T58-run-lifecycle` · **PR title** `T58: integrate the run lifecycle with save resume`

## Purpose

Bind the T53 event plan, T57 rewards and the generated floor into one
persistent run macro-state: sequential 7/8-event progression across the
ten-floor stair-step, conquest, retreat, the great regression, run-scoped
anchor reset, and JSON save resume.

## Contract

- `RunLifecycle` (Core-pure) composes `RunEventProgress` + `RunRewardInventory`
  for one stair-step. Floor advance requires the current floor's event to be
  resolved; advancing off floor ten with a completed boss conquers the run.
- Retreat semantics reuse the T8 `ExpeditionRules` constants: any defeat (or
  voluntary retreat) returns the run to floor one and resets run-scoped
  progress, rewards and anchor states; the third retreat is the great
  regression and resets the retreat count. Roster death bookkeeping remains
  owned by `ExpeditionRules` and is integrated in the meta lane (T61).
- `RunRewardInventory` gains `Capture`/`Restore` (T57 deferred seam). Restore
  rejects claims that have no completed run event.
- `SaveGame` v1 gains the optional `runLifecycle` snapshot; older saves and
  JsonUtility empty-object round-trips restore as "no run" cleanly.
- The generated floor host reports enemy-team victory through
  `SetDefeatedHandler` (Configure signature unchanged); the renderer routes it
  into `RunLifecycle.Retreat` and rebuilds floor one.
- `ForestFloorRenderer` persists one `RunLifecycle` across rebuilds, saves to
  `persistentDataPath/run-lifecycle.json` after every lifecycle mutation, and
  resumes from it on the next play session. `-qaFreshRun` (QA-only) deletes
  the save before starting.
- v0 pacing: floors without a scheduled event have no authored content yet
  (T59 owns it), so the default flow fast-forwards to the next pending event
  floor. The `runFloorNumber` inspector override remains a QA preview seam.

## Explicitly out of scope

- Roster death/missing bookkeeping wiring (T61 meta lane), non-event floor
  content (T59), defeat/retreat presentation and reward UI (T60), economy
  values (owner-frozen), camp/shortcut re-ascent (T61).
