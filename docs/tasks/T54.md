# T54 — Generated floor encounter integration

**Branch** `task/T54-generated-encounter-integration` · **PR title** `T54: wire generated floor encounters`

## Purpose

Connect the T53 run slot, existing FloorNode encounter composition, and T52
entry transition in a desktop-runnable generated map.

## Contract

- Only a floor selected by the T53 plan activates a generated encounter.
- The floor lazily binds one matching ordinary/boss node through
  `FloorNodeBinder` and spawns the composed enemy count at that node.
- Entering the trigger holds only direct player locomotion for 0.45 seconds,
  then restores control and enables real-time enemy telegraphs.
- Fork traversal refuses entry while the encounter is unresolved and accepts
  the same trigger after resolution.
- `R` is an explicit temporary QA resolution path. T56 replaces it with actual
  HP/death-driven combat completion.

## Explicitly out of scope

- HP, damage, death, rewards, cadence, multi-enemy utility AI, and complete Run
  lifecycle. Those remain T55–T58 dependencies.

## Verification

- EditMode bridge tests cover composed enemy spawn, local hold, real-time
  activation, kind mismatch rejection, resolution callback, and cleanup.
- Full EditMode, FloorEncounter Windows64 build, and desktop input/log evidence
  are required before completion.
