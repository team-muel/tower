## A. 오빗 카메라 (18 §1)

1. `OrbitCameraRig` 신규 (기존 IsoCameraRig 대체가 아니라 **전투 전용 모드로 공존** — 탐험/캠프는 기존 추적 유지, 전투 진입 시 오빗 모드): 포커스 대상(활성 턴 유닛, 없으면 회귀자) LookAt 추적.
2. 우클릭 드래그 = yaw/pitch 궤도 회전, Q/E = yaw 스텝, 스크롤 = 줌. pitch·줌 클램프.
3. **파라미터 전부 데이터화** (직렬화 필드 + 기본값: pitch 20~70°, 줌 6~22m, 회전 감도·감쇠) — -devcam 튜닝 모드와 호환.
4. 전투 중 활성 유닛이 바뀌면 포커스 부드럽게 전환(감쇠 이동).

## B. 불릿타임 지휘 모드 (18 §2, 자원 제약 없음 — v2.6 ②)

1. **스페이스 = 지휘 모드 토글** (전투 중 언제나, 횟수 제한 없음). 턴제 게임이므로 시간 정지가 아니라 **지휘 오버레이 상태**: 연출 감속은 프레젠터 로컬 재생 계수(예: 0.25x)로만 — `Time.timeScale` 건드리지 않는다.
2. 지휘 모드 UI: 아군 유닛 위에 **예비 능력(PendingAbility) 표시** + 클릭 시 장착 슬롯 1~4 팝업 — 쿨타임 능력은 회색+남은 라운드 표시(UX 규칙 2), 클릭으로 `TurnEngine.SetPendingAbility` 호출(실패 사유는 토스트 문구로 표출).
