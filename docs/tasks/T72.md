# T72 — hold the victory result transition

**Branch** `task/T72-result-transition-lock` · **PR title** `T72: lock traversal during encounter result`

The generated-floor victory banner is a readable three-second result moment.
T72 makes that moment authoritative in the run loop: traversal, voluntary
retreat, direct floor advance, and the build-only auto-run driver all wait for
the result presenter to expire.

## Implementation

- `ForestFloorRenderer.IsResultBlocking` is the single presentation gate.
- Exit proximity and fork-trigger traversal reject input while the result is
  visible; holding `R` cannot turn a victory moment into an accidental retreat.
- `AdvanceRunFloor` returns a clear failure until the result expires, so direct
  QA callers cannot bypass the same transition.
- `QaAutoRunDriver` resets its settle timer during the result moment and then
  continues through the normal floor-advance path.
- EditMode covers the lock, expiry, and resumed traversal path.
