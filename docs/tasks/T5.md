# T5 — 동료 AI

브랜치: `task/T5-companion-ai` / PR 제목: `T5: companion AI`
의존: T4 (머지된 상태에서 착수).

## 목표

동료·적의 턴을 자동 결정하는 AI. **명시적 스코어링 함수** — if/switch 분기 증식 금지: 성향은 스코어 가중치 데이터로 표현하고, 새 성향 추가가 가중치 세트 추가로 끝나야 한다.

## v0 규칙 결정

- 구조: 후보 행동 열거(이동 후보 셀 × 사용 가능 능력 × 유효 대상) → 스코어링 → 최고점 실행. 동점은 결정적 타이브레이크 (행동 종류 → 대상 id).
- 공통 스코어 요소: 예상 데미지, 킬 가능 보너스, 사거리 유지, 위험(인접 적 수), 아군 보호(보호 대상과의 거리).
- **연계 인지 (필수)**: 소모 가능 마크를 보유한 적 대상 Consume 행동에 큰 보너스. Apply 행동은 아군 중 Consume 보유자가 있을 때 보너스. Amplify는 강한 아군 행동 직전(속도 순서상 다음 아군)에 보너스.
- 성향 가중치 v0: `Aggressive`(데미지·킬 가중 ↑, 위험 페널티 ↓), `Protective`(아군 보호 가중 ↑, 위험 페널티 ↑). 가중치는 데이터 구조(성향→가중치 세트 매핑)로.
- 적 AI도 같은 스코어러 사용 (성향 Aggressive 기본).
