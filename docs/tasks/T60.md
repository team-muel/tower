# T60 — Play HUD and combat readability

**Branch** `task/T60-play-hud` · **PR title** `T60: read the run and the fight from one HUD`

## Contract

- `PlayRunHudComposer` (pure, EditMode-testable) composes the HUD model from
  live Core state: run line (floor/events/retreats or CONQUERED), reward
  totals, player HP line/fraction, and ability slots with cooldown fractions
  (`CharacterState.RemainingCooldownSeconds` over `AbilityDef.CooldownSeconds`).
- `PlayRunHud` (provisional IMGUI, same lane as `EncounterResultPresenter`)
  renders the model: top-left run panel, top-right rewards, bottom combat bar
  with HP fill and slot cooldown overlays. Final styling (클레르 옵스퀴르 기조)
  is an art pass on top of this data spine.
- Combat readability: the runtime fallback floor camera gains the T39
  `CameraOcclusionFadeController` so trees between the camera and the player
  fade during traversal and combat.
- **Owner-frozen surfaces stay absent**: no command UI, no counter UI, no
  slot-count manipulation. The HUD is read-only presentation.

## Explicitly out of scope

Command/counter/order UI (frozen), reward choice UI, final art styling,
minimap (M-key DE overlay is its own later lane).
