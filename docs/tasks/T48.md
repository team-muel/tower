# T48 — Slow-mo spike v0

**Branch** `task/T48-slowmo-spike` · **PR title** `T48: slow-mo spike`

## Purpose

This is a problem-reproduction spike, not a solution implementation.

1. The preview must convey the feel of holding Space for slow motion.
2. It must visibly reproduce the experience of watching an unintelligent companion get hit.

Commands, ability key bindings, counter gameplay effects (damage, stagger, or cancellation), HP, waves, progression, economy, narrative, and camp are explicitly out of scope. The owner decides those after previewing this spike.

## A. Tower.Core

All types in this section are pure, scene-free, and EditMode-testable.

### SlowMoResource

- Stores `charge` in the inclusive range `0..1`.
- `Drain(dt)`, `Recharge(dt)`, and `CanEngage` enforce a minimum-engage threshold: after depletion it cannot be engaged again until the threshold is restored.
- Its integration must be frame-rate independent: `1 x 0.5s` and `50 x 0.01s` have the same result.

### TelegraphState

- State values: `Idle`, `Windup`, `Commit`, `Recover`.
- `Advance(float dt)` uses injected phase durations and is deterministic.
- `Commit` cannot be re-entered and can never be reached without a preceding `Windup`.

### CounterWindow

Both functions are pure measurement only and use scaled game-time values. They mutate no game state.

- `ClassifyInstant(pressTime)` classifies Windup using `a * W` and `b * W` as `Early`, `Clean`, or `Late`. A press during Commit or no input is `Missed`.
- `ClassifyCoverage(holdStart, holdEnd)` tests whether the Commit start is covered and measures coverage of the late Windup region `b * W .. W`. At or above the configured threshold is Clean-equivalent.

## B. Tower.Combat

### TimeDilationService

- The sole writer of `Time.timeScale`; scales `Time.fixedDeltaTime` alongside it and exposes `float Current`.
- Real-time paths (input, resource drain/recharge, and camera feel) use `unscaledDeltaTime`. `FixedIsoFollowCameraRig` already does so and must not be changed.

### SlowMoInput

- Holding Space engages slow motion only while `SlowMoResource.CanEngage`; release restores normal time.
- This is the only source of press/hold timestamps supplied to both CounterWindow classifications.

### PillbugBrain

- A pillbug using a sphere primitive only; no asset dependency.
- Drives `TelegraphState`: `Idle -> Windup` telegraph, then a short `Commit` dash.
- Targets the nearest by metre distance among player and companion; equal distance always selects the player. This must be deterministic.
- Commit contact produces a visual flash only. No damage, knockback, or HP.

### CompanionBody

- Body visual: `HumanMale_Character_FREE`, `PC_Locomotion.controller`, distinct material tint.
- Follows the player to leash distance, stops, and faces the nearest enemy.
- Rigidbody is always `isKinematic = true`.
- No AI decisions, abilities, commands, or HP.
- Animation clips must be obtained from the Blink FBX sub-assets with `LoadAllAssetsAtPath` and exact names. Use only `Idle`, `RunForward`, and `Sprint`; there is no Walk clip.

### CombatEncounterHost

- Owns a `CombatState` from T49 and spawns exactly one pillbug plus one companion into the spike scene.
- No wave, floor-lock, or floor-progress execution.

### World-space debug

- During Windup, a growing ring appears at the pillbug's feet.
- Only coverage classification colours the ring (Clean-equivalent / below threshold / Missed, three configured colours).
- Instant classification writes `Debug.Log` only; it is not drawn on screen.

## D. Provisional serialized tuning

All values below must be serialized (ScriptableObject or `[SerializeField]`), never hard-coded. They are owner-tunable and are **PROVISIONAL**.

| Setting | Value |
| --- | ---: |
| slow time scale | 0.25 |
| full drain | 2.5 s |
| full recharge | 8 s |
| minimum engage charge | 0.3 |
| windup | 0.9 s |
| commit | 0.25 s |
| recover | 0.6 s |
| instant boundaries `a`, `b` | 0.33, 0.78 |
| coverage threshold | 0.5 |
| awareness radius | 12 m |
| windup trigger distance | 2.5 m |
| dash range | 3 m |
| companion leash | 4 m |

All distances are BG3-style metres, which is the project convention.

## E. EditMode tests

Create tests under `Assets/_Tower/Tests/EditMode/`.

- `SlowMoResourceTests`: depletion forces release, recharge is monotonic, minimum-engage boundary, and frame-rate independence.
- `TelegraphStateTests`: Windup always precedes Commit, Commit cannot re-enter, and complete cycle duration equals phase-duration sum.
- `CounterWindowTests`: exact zone boundaries, press during Commit is Missed, coverage-threshold boundary, and at least one instant/coverage disagreement (for example, a clean early press immediately released has insufficient coverage).
