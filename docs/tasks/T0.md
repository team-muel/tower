# T0 — 프로젝트 규약 부트스트랩

브랜치: `task/T0-project-conventions` / PR 제목: `T0: project conventions & structure`

## 목표

Unity 6000.3.19f1 URP 프로젝트(이미 생성돼 있음)에 팀 규약 뼈대를 세운다. 게임 코드는 아직 쓰지 않는다.

## 산출물

1. 폴더 구조 생성 (빈 폴더는 `.gitkeep`):
   ```
   Assets/_Tower/
     Scripts/{Core,Combat,Gen,UI}
     Data/{Characters,Abilities,Marks}
     Scenes/            (Boot.unity, Loadout.unity, Expedition.unity — 빈 씬 3개)
     Prefabs/
     Tests/{EditMode}
   ```
2. asmdef 4개: `Tower.Core`(엔진 의존 최소), `Tower.Combat`(→Core), `Tower.Gen`(→Core), `Tower.UI`(→Core,Combat). Tests용 `Tower.Tests.EditMode`(→전체, Test Framework 참조).
3. Unity Test Framework 패키지 확인/추가 (`com.unity.test-framework`, manifest.json).
4. `docs/CONVENTIONS.md`: C# 스타일(파일당 1클래스, namespace `Tower.*`, private 필드 `_camelCase`), "코어 로직은 MonoBehaviour 밖" 원칙, ScriptableObject 데이터 주도 원칙(AGENTS.md §규약 5).
5. 스모크 테스트 1개 (`Tower.Tests.EditMode`에 항상 통과하는 테스트 — 테스트 러너 배선 확인용).

## 제약

- .meta 파일: 에디터 없이 작업할 경우 asmdef/씬의 .meta 생성이 안 됨 → **가능하면 Unity 배치모드로 1회 열어 .meta 생성 후 커밋** (env: ALLUSERSPROFILE=C:\ProgramData 필수). 라이선스 미활성으로 배치모드 실패 시: .meta 없이 커밋하고 PR 본문에 "에디터 1회 오픈 필요" 명시.
- main 직push 금지. PR로.
