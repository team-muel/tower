## 산출물

1. `docs/licenses.md`.
   - 커밋 가능한 출처와 조건부 출처를 분리한다.
   - 현재 레포에 들어온 Poly Haven 텍스처 3종과 Unity material 파생물을 ledger에 기록한다.
   - screenshot/reference image는 재배포 자산이 아니라 참조로만 둔다.
2. T34/T35용 체크리스트.
   - source URL, license URL, 가공 내용, Unity import 검증을 PR 전에 확인한다.

## 완료 정의

- `docs/licenses.md`가 존재한다.
- 현재 `Assets/_Tower/Art`의 `asphalt_01`, `gravel_floor_02`, `brick_moss_001`, 관련 materials가 모두 ledger에 들어간다.
