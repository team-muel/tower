# T9 — 계측·시뮬 게이트

브랜치: `task/T9-metrics-sim` / PR 제목: `T9: combat metrics + AI-vs-AI sim`
의존: T8 (머지됨). 슬라이스 마지막 태스크.

## 목표

밸런싱·페이싱 검증 인프라의 씨앗: (a) 전투 소요시간 계측, (b) AI vs AI 자동전투 시뮬레이터 — **에이전트가 배치모드로 돌려 결과를 읽을 수 있는 루프**.

## 산출물

1. `CombatMetrics` (Tower.Core): 전투당 라운드 수·행동 수·유닛별 데미지·전투 시작/종료 타임스탬프 수집. TurnEngine/AbilityResolver에 옵저버 훅 (기존 API 파괴 금지 — 이벤트 or 옵셔널 리스너).
2. `AutoBattleSimulator` (Tower.Core): 파티 A vs 파티 B, 양측 모두 AiTurnDriver(Core)로 N판 자동 실행 (프레젠터 없음 = 최고속). 시드 주입. 결과: 승률, 평균 라운드, 평균 생존자, 유닛별 킬/데미지 집계.
3. **배치모드 진입점**: `Tower.Core.SimCli.Run(args)` 스타일의 static 메서드 + Editor 스크립트(`Assets/_Tower/Scripts/Editor/SimRunner.cs`, Editor asmdef 신규)로 `-executeMethod Tower.EditorTools.SimRunner.RunDefault` 호출 시 JSON 결과를 `C:\dev\_setup\sim-result.json`(경로는 커맨드라인 인자로 덮어쓰기 가능)에 쓴다.
4. EditMode 테스트: 메트릭 수집 정확성(고정 시나리오에서 라운드/행동 수), 시뮬 결정성(같은 시드 = 같은 결과), 시뮬이 종료됨(무한 루프 가드 — 최대 라운드 상한).
5. README 절: `docs/CONVENTIONS.md`에 시뮬 실행법 1문단 추가.
