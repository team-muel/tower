# T32 — FloorGraph Terrain Preview Scene

근거: vault `00 Current Status` 즉시 다음 액션, `75 §4`, `76 Floor Preview and Asset Sourcing Plan`.

목표: `_FloorPreview`의 execute_code 지형 데모를 정식 코드 경로로 대체한다. 새 게임 메커니즘을 만들지 말고, 이미 머지된 `FloorGraph`/`HeightFieldFactory`/`FloorTerrainMeshBuilder`를 씬에서 소비한다.

## 산출물

1. `Tower.UI.FloorGraphTerrainPreview` MonoBehaviour.
   - `FloorGenerator.Generate`로 노드/route 골격 생성.
   - 각 `FloorNode`를 `HeightFieldFactory.ForNode(graph.Seed, node, biome)`에 바인딩.
   - `FloorTerrainMeshBuilder.Build`로 메시 생성.
   - 생성물은 `_GeneratedFloorGraphTerrain` 루트 아래에만 둔다.
2. `_FloorPreview.unity`에 프리뷰 컨트롤러 루트 추가.
3. `Tower.EditorTools.FloorPreviewCapture` 배치모드 캡처 진입점.
   - `_FloorPreview`를 열고 프리뷰 지형을 rebuild한 뒤 PNG를 저장한다.
   - 기본 출력: `C:\dev\_setup\floor-preview-t32.png`.
4. EditMode 테스트.
   - Rebuild가 graph node 수만큼 메시 세그먼트를 만든다.
   - Rebuild 반복 시 이전 생성 루트를 교체하고 중복 루트를 남기지 않는다.

## 완료 정의

- Unity EditMode 전체 통과.
- `-executeMethod Tower.EditorTools.FloorPreviewCapture.Capture`로 PNG 생성 성공.
- 기존 수동 프리뷰/PolyHaven 후보 자산은 보존하되, 정식 코드 프리뷰 루트와 이름으로 분리.
- PR/커밋 설명에 `_FloorPreview`가 아직 시각 QA 스크린샷 확인 전인지, 또는 확인 완료인지 명시.

## 함정

- Unity 6000.3.19f1에서 `-quit`가 테스트 러너보다 먼저 종료되는 경우가 있다. 그런 경우 기존 성공 패턴대로 `-batchmode -runTests -testPlatform EditMode`를 `-quit` 없이 실행한다.
- `PC_RPAsset.asset`이 더러워지면 커밋 전 복원한다.
- Art/Screenshots/Data Source 미커밋 파일은 기존 프리뷰 산출물일 수 있으므로 무작정 삭제하지 않는다.
