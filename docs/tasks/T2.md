# T2 — 그리드·이동·카메라

브랜치: `task/T2-grid-movement-camera` / PR 제목: `T2: grid, movement, camera`
의존: T0 (머지됨). T1과 병렬 — **T1의 타입에 의존하지 말 것.**

## 목표

전투 공간의 기반: 그리드 모델, 경로탐색, 아이소 카메라, 타일 하이라이트. 게임 규칙(능력·턴)은 범위 밖.

## 산출물

1. **Tower.Core (순수 C#, 테스트 대상)**:
   - `GridMap`: 직사각 그리드, 셀 통행 가능/차단, 점유자 id. 좌표는 `GridPos(int x, int y)` struct.
   - `Pathfinder`: A* (4방향, 대각선 없음 v0). 경로 없으면 빈 결과 (예외 금지).
   - `GridDistance`: 맨해튼 거리 유틸 (사거리 판정용 — T4가 사용 예정).
2. **Tower.Combat (View, MonoBehaviour)**:
   - `GridView`: GridMap을 프리미티브(Plane/Quad 타일)로 시각화. 머티리얼 인스턴스 최소화.
   - `TileHighlighter`: 셀 hover/선택/사거리 하이라이트 (색상만).
   - `UnitToken`: 캡슐 프리미티브 토큰을 GridPos에 배치·이동 (이동은 코루틴 보간, **연출 스킵 가능하게** — 즉시 완료 API 포함).
   - `IsoCameraRig`: 고정 각도 아이소메트릭 카메라 (회전 4방향 스냅 + 줌 2단계면 충분, 팬).
3. **데모 부트스트랩**: `GridDemoBootstrap` MonoBehaviour — 빈 GameObject에 붙이면 12×12 그리드 + 토큰 3개 생성, 클릭 이동. **씬 파일은 수정하지 말 것** (충돌 방지 — 데모는 코드 생성).
4. **EditMode 테스트**: Pathfinder(직선/우회/차단/불가능 경로), GridMap 점유 규칙.
