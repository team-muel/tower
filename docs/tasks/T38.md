# T38 — FloorEncounterComposer Wiring

근거: vault `00 Current Status`의 남은 실행 항목 `FloorGenerator -> FloorEncounterComposer`, `61 Session Log Archive`의 T26 후속 메모.

목표: `FloorGenerator`/`FloorGraph` skeleton은 그대로 두고, node 내용 lazy binding 시 옛 enemy-count 휴리스틱 대신 `FloorEncounterComposer`와 resolved `EncounterBudget`을 사용한다. 새 전투 기능을 만들지 않는다.

## 산출물

1. `FloorGenParams`가 기본 `EncounterBudgetTable`과 optional `EliteKindSlot`을 보관한다.
2. `FloorNodeBinder.Bind`가 battlefield 크기는 기존처럼 결정적으로 만들되, encounter는 `FloorEncounterComposer.Compose(...)`로 만든다.
3. 기존 entrance/camp/boss/exit 동작은 composer 계약으로 유지한다.
4. EditMode 테스트 갱신.
   - non-entrance combat encounter count가 `EncounterBudget`으로 계산된다.
   - room-kind override가 binder를 통해 실제 encounter count에 반영된다.

## 완료 정의

- Unity EditMode 전체 통과.
- `FloorNodeBinder`에 직접 enemy count 휴리스틱이 남지 않는다.
- `FloorGenerator.Generate`는 node+route skeleton 생성 역할만 유지한다.

## 위임

Claude Code read-only 검토를 먼저 시도한다. 현재 실행 결과는 인증 실패: `Your organization does not have access to Claude. Please login again or contact your administrator.` 따라서 Codex가 직접 구현하고 PR/vault에 기록한다.
