# T75 — deterministic combat teardown

**Branch** `task/T75-combat-teardown-feedback` · **PR title** `T75: clean defeated encounter views`

Victory already drains the final combat feedback before removing the generated
world views. T75 gives defeat the same explicit host-owned teardown contract:
the callback still hands control to the run lifecycle, but dead-world views and
enemy bodies are removed before that handoff. Presentation popups remain owned
by the feedback presenter until their local unscaled lifetime ends.

## Implementation

- `GeneratedFloorEncounterHost.HandlePlayerDefeat` now ends combat
  presentation, clears combat views, and destroys generated enemies before
  invoking the floor/run callback.
- Victory coverage asserts that world teardown does not erase the final-hit
  popup, while defeat coverage asserts that the callback sees no leftover enemy
  bodies or combat views.
